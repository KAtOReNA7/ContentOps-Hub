# 阶段 16：作品价值评分升级 V1

更新时间：2026-05-29

## 核心变化

阶段 16 将“作品识别可信度”和“作品价值评分”拆开处理：

- 识别置信度不再直接给作品价值加分或扣分。
- 识别置信度用于判断评级可信度、是否为预评级、是否需要人工确认。
- 低置信度且未确认时仍允许生成预评级，但会明确提示“不建议直接用于运营决策”。
- 人工确认作品身份后，不再因为原始识别置信度低而封顶评级。

## 新增评分参考

评分仍保留书名、简介、题材、播放量、点击率、完播率等维度，并新增搜索证据相关参考：

- 有声书平台证据优先。
- 电子书平台证据可参考，但权重低于有声书平台。
- 搜索引擎、社交媒体和未知来源只作为辅助。
- 搜索证据中作者匹配会提高可信度和评分解释强度。

## 多书名建议

多书名建议仍输出：

- `avoid`
- `cautious`
- `recommended`
- `strongly_recommended`

建议逻辑更偏运营判断：

- S / A：作品认知或综合价值较高，倾向 `avoid` 或 `cautious`。
- B：通常适合 `recommended`。
- C：包装空间较大，通常 `recommended` 或 `strongly_recommended`。
- D：如果主要问题来自识别风险，先人工确认；如果是包装弱但题材有潜力，则谨慎测试。

## 备注字段

备注继续进入书名、简介和封面 prompt 生成上下文，但不参与作品价值评分。
