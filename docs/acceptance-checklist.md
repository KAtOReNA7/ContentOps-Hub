# 交付验收清单

更新时间：2026-05-30

本清单用于阶段 20 完整交付验收。建议使用脱敏样例数据先跑通，再使用少量真实业务数据复核。验收时不得提交 `.env`、本地数据库或 `uploads/` 下图片。

## 一、启动与环境

- [ ] 执行 `npm install` 成功。
- [ ] 执行 `npm exec -- prisma validate` 成功。
- [ ] 执行 `npm exec -- prisma generate` 成功。
- [ ] 执行 `npm run db:test` 成功。
- [ ] 执行 `npm run dev` 后可以打开首页。
- [ ] `/settings` 不展示 API Key、代理地址详情或本地敏感路径。

## 二、作品录入

- [ ] Excel / CSV 可以上传、预览、校验和入库。
- [ ] 重复作品、空书名、空作者和比例格式异常有明确提示。
- [ ] 封面 URL 可以从导入文件创建远程封面资产。
- [ ] 手动新增作品可以填写业务作品 ID、书名、作者、分类、简介、备注和数据指标。
- [ ] 手动新增作品可以填写封面 URL 或上传本地封面。

## 三、识别与评级

- [ ] 单本识别默认使用 Mock，不调用外部搜索。
- [ ] 真实搜索必须由用户主动选择并确认成本风险。
- [ ] 真实搜索失败时有明确提示，Mock fallback 不会伪装成正式证据。
- [ ] 无关搜索结果不会进入候选、IP 热度证据或评级依据。
- [ ] 可以人工确认作品身份。
- [ ] 未识别或低置信度识别时，评级区域显示预评级提示。
- [ ] 可以生成并保存 SABCD 价值评级。

## 四、书名简介与封面

- [ ] Mock 书名简介生成可用。
- [ ] OpenAI 文本生成只在用户主动选择时调用。
- [ ] OpenAI 配置缺失或调用失败时显示明确错误，不静默回退 Mock。
- [ ] 备注会进入生成上下文，但不会影响评级分数。
- [ ] 当前封面缩略图可以预览，加载失败时有替换提示。
- [ ] 可以运行 Mock 封面评估并人工确认策略。
- [ ] `keep_and_replace_title` 和 `keep_and_optimize_layout` 可以生成 1:1 / 3:4 标题封面。
- [ ] `redraw_cover` 只有用户确认成本后才允许单本调用 Image2。

## 五、审核、测试复盘与效果回流

- [ ] 可以保存最终书名、最终简介、最终封面、审核状态、审核人和备注。
- [ ] 多书名测试结果导入使用独立模板和独立入口。
- [ ] 对照组与实验组数据可以生成复盘结论。
- [ ] 可以生成人工可解释的效果回流洞察和策略标签。
- [ ] 效果洞察不会自动覆盖最终采用结果。

## 六、批量任务

- [ ] 作品列表勾选作品后可以创建批量任务。
- [ ] 批量任务使用本地顺序执行，单条失败不影响整批。
- [ ] 批量识别可以显式选择 Mock 或真实搜索。
- [ ] 批量书名简介生成可以显式选择 Mock 或 OpenAI。
- [ ] 选择真实搜索或 OpenAI 时必须确认成本风险。
- [ ] 任务详情可以看到总数、成功、失败、跳过数量和每条实际 provider。

## 七、导出交付

- [ ] 单本、全部、筛选和勾选 Excel 导出可用。
- [ ] Excel 保留 `作品运营建议` 总表和 6 个分类工作表。
- [ ] 长简介、理由、风险和证据列可以换行阅读。
- [ ] 缺少识别、评级、生成或封面结果时不会导致导出失败。
- [ ] ZIP 交付包包含 Excel 和已有本地最终封面。
- [ ] 作品缺少最终封面时 ZIP 仍能导出。
- [ ] 导出内容不包含 API Key、服务器绝对路径或本地数据库路径。

## 八、质量检查

- [ ] `npm run typecheck`
- [ ] `npm run lint`
- [ ] `npm run build`
- [ ] `npm run db:test`
