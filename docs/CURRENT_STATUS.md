## 阶段 9 补丁：导入封面 URL

更新时间：2026-05-24

- Excel/CSV 导入现在支持从封面字段读取远程图片地址，并自动创建远程封面资产。
- 支持的封面列名包括：`封面地址`、`封面URL`、`封面链接`、`封面文件名`、`coverUrl`、`cover_url`、`coverFileName`。
- 手动上传封面仍作为备用能力保留。
- 当前不下载远程封面入库，不接 OpenAI 视觉评估，不接图片生成 API。
- 作品详情页可以预览导入封面 URL，并直接运行 Mock 封面评估。
