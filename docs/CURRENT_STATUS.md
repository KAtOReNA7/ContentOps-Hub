## 下一步建议

优先手动测试阶段 15：

1. 从首页或作品列表进入“手动新增作品”。
2. 分别测试只填基础信息、填写远程封面 URL、上传本地封面三种路径。
3. 创建成功后确认跳转作品详情页。
4. 在未识别、低置信度识别、人工确认识别三种状态下查看评级提示。
5. 在备注中填写运营卖点，运行书名简介生成，确认 evidence 中能看到备注已进入生成上下文。
