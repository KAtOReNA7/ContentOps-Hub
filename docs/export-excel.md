# Excel / ZIP 导出

## 导出入口

- 作品列表页：导出当前筛选 Excel、导出已勾选 Excel、导出当前筛选 ZIP 交付包。
- 作品详情页：导出当前作品 Excel。

## API 路由

- `GET /api/export/works`：导出全部作品或当前筛选作品。
- `GET /api/export/works?ids=id1,id2`：导出指定勾选作品。
- `GET /api/export/works/zip`：导出当前筛选 ZIP 交付包。
- `GET /api/export/works/[id]`：导出单本作品。

支持查询参数：

- `title`
- `author`
- `category`
- `reviewStatus`
- `rating`
- `ids`

## 导出字段

Excel 聚合以下数据：

- 作品基础信息：作品ID、原书名、作者、品类、简介、播放量、点击率、完播率、封面文件名、封面地址。
- 识别结果：匹配作品名、匹配作者、置信度、识别理由、风险、人工确认结果。
- 评级结果：评级、分数、置信度、理由、风险、证据、多书名建议。
- 书名简介生成结果：provider、策略、新书名 1-5、新版简介、封面 prompt。
- 封面评估：评分、评级、优点、问题、处理策略、处理理由、人工确认策略和备注。
- 阶段 11 原图换标题结果：1:1 / 3:4 预览地址。
- 阶段 12 Image2 重绘结果：provider、状态、prompt、结果摘要、1:1 / 3:4 预览地址。
- 阶段 13 最终采用结果：审核状态、最终书名、最终简介、最终封面地址、最终封面来源、审核备注、审核人、审核时间。
- 阶段 18 测试复盘：实验名称、对照组和实验组指标、CTR / 转化率变化、复盘结论、置信度和推荐动作。
- 阶段 19 效果回流：实际结果判断、评级准确性、书名策略效果、封面策略效果、关键提升指标、策略标签、摘要和风险提示。
- 导出时间。

导出优先展示 `Work` 上保存的最终采用结果，同时保留识别、评级、生成、封面评估和封面处理建议摘要。

## 工作表结构

为兼容已有交付方式，Excel 保留原有 `作品运营建议` 总表，同时新增 6 个分类工作表：

1. `运营总览`：适合运营人员快速扫描作品状态、评级、封面策略、复盘动作和最终采用结果。
2. `识别与评级详情`：保存识别匹配、人工确认、评级理由、风险和证据。
3. `书名简介方案`：保存生成来源、策略、新书名 1-5、新版简介和封面 Prompt。
4. `封面处理`：保存封面资产、评估结果、人工确认策略、原图换标题和 Image2 摘要。
5. `测试复盘`：保存实验指标、变化结果、结论和推荐动作。
6. `效果回流`：保存实际结果判断、评分校准、策略效果、标签和风险提示。

缺少某个阶段结果时，对应工作表字段留空，不会导致导出失败。

## 缺失数据处理

- 未生成的识别、评级、书名简介、封面评估字段留空。
- 数组字段使用中文分号拼接。
- JSON 字段解析失败时使用空值，不让导出接口崩溃。
- 不导出 API key。
- 不导出服务器本地绝对路径。

## ZIP 交付包

ZIP 包包含：

- `作品运营建议.xlsx`
- 可读取到的最终采用封面文件

每本作品的封面放入独立目录，目录名优先使用作品 ID 或作品名。没有最终封面、远程封面不可下载或本地文件缺失时，不会中断整个 ZIP 导出，Excel 中仍会保留对应作品数据。

## V1 限制

- 暂不支持自定义导出字段。
- ZIP 包不重新生成图片，只打包已有结果。
- 远程封面不在导出阶段强制下载。
- 导出的预览地址为应用内 API 相对路径，不是公网 CDN 地址。

## 手动测试方式

1. 运行 `npm run dev`。
2. 进入作品列表页。
3. 使用书名、作者、品类、审核状态或评级筛选。
4. 点击“导出当前筛选 Excel”，确认下载 `.xlsx`。
5. 勾选部分作品，点击“导出已勾选 Excel”，确认只导出勾选作品。
6. 点击“导出当前筛选 ZIP 交付包”，确认 ZIP 中包含 Excel 和已有最终封面。
7. 进入任意作品详情页，点击“导出当前作品 Excel”。
8. 检查缺失识别、评级、生成或封面评估的数据不会导致导出失败。
9. 打开 Excel，确认原始总表和 6 个分类工作表均存在。
