# Excel 导出 V1

更新时间：2026-05-24

## 导出入口

- 作品列表页：点击“导出全部作品 Excel”，下载全部作品的运营建议表。
- 作品详情页：点击“导出当前作品 Excel”，只下载当前作品的运营建议表。

## API

- `GET /api/export/works`：导出全部作品。
- `GET /api/export/works/[id]`：导出单本作品。

接口返回 `.xlsx` 文件，Sheet 名称为“作品运营建议”。失败时返回结构化 JSON 错误。

## 导出字段

V1 聚合以下数据：

- 作品基础信息：作品ID、原书名、作者、品类、简介、播放量、点击率、完播率、封面文件名、封面地址。
- 作品识别：匹配作品名、匹配作者、置信度、识别理由、风险、人工确认结果。
- 价值评级：评级、分数、置信度、理由、风险、证据、多书名运营建议。
- 书名简介生成：provider、生成策略、策略说明、新书名 1-5、新版简介、封面 prompt。
- 封面评估：评分、评级、优点、问题、处理策略、处理理由、人工确认策略和备注。
- 导出时间。

## 缺失数据处理

- 未生成的识别、评级、书名简介、封面评估字段留空。
- 数组字段使用中文分号拼接。
- JSON 字段解析失败时写入“解析失败”，不会导致导出接口崩溃。
- 不导出 API key、本地绝对路径或服务器内部路径。

## V1 限制

- 暂不支持勾选批量导出。
- 暂不支持自定义导出字段。
- 暂不支持 ZIP 导出。
- 暂不导出真实封面图片文件，只导出远程封面地址和封面评估结果。

## 手动测试方式

1. 运行 `npm run dev`。
2. 进入作品列表页。
3. 点击“导出全部作品 Excel”。
4. 确认浏览器下载 `.xlsx` 文件。
5. 打开 Excel，检查作品基础信息、识别、评级、书名简介生成、封面评估和人工确认字段。
6. 进入任意作品详情页。
7. 点击“导出当前作品 Excel”。
8. 确认导出文件只包含当前作品。
9. 检查缺失识别/评级/生成/封面评估的数据不会导致导出失败。

## 阶段 11 补充

Excel 导出现在包含新版封面生成结果的预览地址字段：
- 新版封面1:1地址
- 新版封面3:4地址

该字段只导出应用内预览 API 地址，不导出服务器本地绝对路径，也不导出真实图片文件。

## 阶段 12 补充

Excel 导出现在包含 ChatGPT Image2 重绘封面摘要字段：

- 重绘封面 provider
- 重绘封面状态
- 重绘封面 prompt
- 重绘结果摘要
- 重绘1:1是否已生成
- 重绘3:4是否已生成
- 重绘封面1:1地址
- 重绘封面3:4地址

这些字段只导出 `provider=chatgpt_image2` 且 `strategy=redraw_cover` 的最近结果。图片地址使用应用内 `/api/cover-renders/{id}/file` 相对路径，不导出服务器本地绝对路径，不导出 API key，也不导出真实图片文件。

## 阶段 13 补充

Excel 导出现在包含人工审核和最终采用结果字段：

- 审核状态
- 最终书名
- 最终简介
- 最终封面地址
- 最终封面来源
- 审核备注
- 审核人
- 审核时间

导出优先展示 `Work` 上保存的最终采用结果；如果最终书名或最终简介为空，则保留原书名、当前简介或最近一次生成建议作为参考。原识别、评级、书名简介建议、封面评估、阶段 11 和阶段 12 的摘要字段继续保留，便于追溯采用依据。
