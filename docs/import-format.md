# 批量导入表格格式

支持文件类型：

- `.xlsx`
- `.csv`

首行必须是表头。字段顺序建议与模板一致，但系统按表头名称读取。

## 字段说明

| 字段 | 是否必填 | 格式 | 说明 |
| --- | --- | --- | --- |
| 作品ID | 是 | 文本 | 外部作品唯一标识，用于重复判断 |
| 原书名 | 是 | 文本 | 作品原始书名，不能为空 |
| 作者名 | 是 | 文本 | 作者名称，不能为空 |
| 原简介 | 是 | 文本 | 作品简介，不能为空 |
| 封面文件名 | 否 | 文本 | 对应封面文件名称，缺失会提示但不阻止导入 |
| 品类 | 否 | 文本 | 如都市情感、玄幻、悬疑等 |
| 当前播放量 | 否 | 非负整数 | 支持普通数字，如 `12000` |
| 当前点击率 | 否 | 百分比或小数 | 支持 `12%`、`0.12`、`12` |
| 当前完播率 | 否 | 百分比或小数 | 支持 `35%`、`0.35`、`35` |
| 备注 | 否 | 文本 | 运营备注 |

## 预览校验

导入前会显示预览表格，并标记：

- 缺失必填字段
- 重复作品
- 空书名
- 空作者
- 点击率格式异常
- 完播率格式异常
- 封面文件名缺失

其中“封面文件名缺失”为提醒，不阻止导入；其他错误会阻止对应行导入。

## 封面图片地址

封面字段现在既可以填写本地封面文件名，也可以填写远程图片 URL。

兼容列名：
- `封面地址`
- `封面URL`
- `封面链接`
- `封面文件名`
- `coverUrl`
- `cover_url`
- `coverFileName`

如果单元格内容以 `http://` 或 `https://` 开头，系统会在导入时创建远程封面资产，并在作品详情页直接预览。导入阶段不会下载图片，也不会调用 OpenAI 视觉评估或图片生成 API。手动上传封面仍作为备用替换方式保留。
