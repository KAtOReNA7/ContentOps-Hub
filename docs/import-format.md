# 作品批量导入格式

作品批量导入支持 `.xlsx` 和 `.csv`。第一行必须是表头，每行只填写一本作品。

## 推荐表头

| 字段 | 重要程度 | 格式 | 说明 |
| --- | --- | --- | --- |
| 作品 ID | 强烈建议 | 文本 | 平台后台、Excel 清单或 CP 侧作品编号，不是系统内部主键 |
| 书名 | 必填 | 文本 | 当前作品名，不能为空 |
| 作者 | 强烈建议 | 文本 | 用于搜索识别和重复判断 |
| 分类 | 强烈建议 | 文本 | 例如都市、悬疑、言情、玄幻 |
| 简介 | 强烈建议 | 文本 | 用于识别和包装判断 |
| 备注 | 选填 | 文本 | 运营上下文，不作为作品价值评分依据 |
| 封面文件 / 封面地址 | 选填 | 文本或 URL | 支持文件名或 `http://`、`https://` 图片地址 |
| 当前播放量 | 选填 | 非负整数 | 例如 `120000` |
| 当前点击率 | 选填 | 百分比或小数 | 支持 `12%`、`0.12`、`12` |
| 当前完播率 | 选填 | 百分比或小数 | 支持 `35%`、`0.35`、`35` |

## 兼容表头

- 作品 ID：`作品ID`、`作品 ID`、`业务作品ID`、`externalId`、`sourceWorkId`
- 书名：`书名`、`原书名`、`作品名`、`标题`、`title`
- 作者：`作者`、`作者名`、`author`
- 分类：`分类`、`品类`、`题材`、`category`
- 简介：`简介`、`原简介`、`内容简介`、`intro`、`description`
- 备注：`备注`、`运营备注`、`notes`、`remark`
- 封面：`封面`、`封面文件`、`封面地址`、`封面URL`、`封面链接`、`封面文件名`、`cover`、`coverUrl`、`cover_url`、`coverFileName`
- 播放量：`播放量`、`当前播放量`、`currentPlays`、`playCount`
- 点击率：`点击率`、`当前点击率`、`CTR`、`ctr`、`currentCtr`
- 完播率：`完播率`、`当前完播率`、`finishRate`、`currentFinish`

## 填写规则

- 不要使用合并单元格。
- 不要给 Excel 设置密码。
- 表头不要带异常空格。
- 不要上传 Excel 临时副本。
- 建议单次导入不超过 500 行，便于定位单行错误。
- 空行会跳过；单行错误不会阻止其他有效行入库。
- 作品 ID 重复或书名 + 作者重复会在预览中提示，导入时重复作品会跳过。
- 封面字段填写 `http://` 或 `https://` 图片地址时，会创建远程封面资产，但不会在导入阶段下载图片。

## 模板

页面提供“下载作品导入模板”按钮，对应文件为：

```text
sample/input-template.xlsx
```

多书名测试结果导入使用独立模板和独立入口，不要与作品清单混用。
