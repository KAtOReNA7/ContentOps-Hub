# 上传文件填写规则

## 作品清单导入

作品清单导入入口为 `/import`。支持 `.xlsx` 和 `.csv`。

### 基础要求

- 第一行必须是表头。
- 每行只填写一本作品。
- 不要使用合并单元格。
- 不要给 Excel 设置密码。
- 表头不要带异常空格。
- 不要上传 Excel 临时副本文件。
- 建议单次不超过 500 行。

### 必填与建议字段

- 必填：书名。
- 强烈建议：作品 ID、作者、简介、分类。
- 选填：备注、封面文件 / 封面地址、当前播放量、当前点击率、当前完播率。

### 校验行为

- 文件无法读取、没有数据、缺少书名表头时，页面会直接提示。
- 空行会跳过。
- 播放量必须是非负整数。
- 点击率、完播率支持百分比或小数形式。
- 封面地址如填写 URL，必须以 `http://` 或 `https://` 开头。
- 空书名只会阻止当前行导入，不影响其他有效行。
- 作品 ID 重复或书名 + 作者重复会在预览中提醒，实际导入时重复作品会跳过。

页面可下载官方模板：`sample/input-template.xlsx`。

## 多书名测试结果导入

多书名测试结果导入入口为 `/experiments/import`，使用独立模板：

```text
sample/experiment-results-template.xlsx
```

测试结果导入用于回流对照组和实验组数据，不要与作品清单模板混用。
