# 多书名测试结果导入填写规则

多书名测试结果导入用于回流实验结束后的对照组和实验组数据，不是作品基础信息导入。

## 基础要求

- 支持 `.xlsx` 和 `.csv`。
- 第一行必须是表头，每一行代表一个测试组结果。
- 同一个作品至少需要 1 行对照组和 1 行实验组，才能生成完整复盘。
- 不要合并单元格，不要设置 Excel 密码。
- 表头不要带多余空格或特殊符号。
- 不要上传临时副本，例如 `experiment-results -1.xlsx`。
- 建议单次导入不超过 1000 行。

## 关键字段

- 必填：组别，以及作品 ID 或书名。
- 点击率或点击量至少填写一个。
- 曝光量建议填写，用于判断数据可靠性。
- 实验名称、实验组名称、日期、转化率、完播率、播放量强烈建议填写。
- 简介、封面地址、收入、备注为选填。

## 组别

支持以下写法：

- 对照组：`对照组`、`control`
- 实验组：`实验组`、`variant`

## 数据格式

- 曝光量、点击量、播放量、转化量：非负整数。
- 点击率、转化率、完播率：支持 `8.5%` 或 `0.085`。
- 收入：数字，不要带“元”。
- 日期：`YYYY-MM-DD`。
- 封面 URL：必须以 `http://` 或 `https://` 开头。

## 兼容表头

- 实验名称：`实验名称`、`测试名称`、`批次名称`、`experimentName`
- 作品 ID：`作品ID`、`作品 ID`、`业务作品ID`、`externalId`、`sourceWorkId`
- 书名：`书名`、`作品名`、`title`
- 作者：`作者`、`作者名`、`author`
- 组别：`组别`、`分组`、`groupType`、`group`
- 实验组名称：`实验组名称`、`版本名称`、`版本`、`variantName`
- 测试书名：`测试书名`、`实验书名`、`多书名`、`titleVariant`、`testTitle`
- 测试简介：`测试简介`、`实验简介`、`introVariant`、`testIntro`
- 封面地址：`封面`、`封面地址`、`封面URL`、`coverUrl`、`testCover`
- 曝光量：`曝光量`、`展示量`、`exposureCount`、`impressions`
- 点击量：`点击量`、`clickCount`、`clicks`
- 点击率：`点击率`、`CTR`、`ctr`
- 播放量：`播放量`、`playCount`、`plays`
- 转化量：`转化量`、`conversionCount`、`conversions`
- 转化率：`转化率`、`conversionRate`
- 完播率：`完播率`、`finishRate`、`completionRate`
- 收入：`收入`、`revenue`
- 开始日期：`测试开始日期`、`开始日期`、`testStartDate`、`startDate`
- 结束日期：`测试结束日期`、`结束日期`、`testEndDate`、`endDate`
- 备注：`备注`、`note`、`notes`、`remark`

## 常见错误

- 组别写成其他文本：改为“对照组”或“实验组”。
- 比例字段写成中文：改为 `8.5%` 或 `0.085`。
- 数量字段带中文单位：改为完整非负整数。
- 日期顺序错误：结束日期不能早于开始日期。
- 匹配不到作品：优先检查作品 ID，再检查书名和作者。

## 复盘触发

系统按“作品 + 实验名称”聚合。同一实验需要同时存在对照组和实验组。缺少任意一组时，数据仍可导入，但显示暂无法复盘。

复盘不会自动覆盖最终采用结果。只有人工确认后，胜出版本才会写入最终采用结果。
