# 脱敏样例数据指南

更新时间：2026-05-30

阶段 20 验收建议使用虚构作品或已脱敏数据，不要把客户真实资料、真实封面、账号信息或 API Key 提交到 Git。

## 作品清单样例

建议准备 6-10 条作品，覆盖：

| 场景 | 建议内容 |
| --- | --- |
| 基础正常数据 | 书名、作者、分类、简介和业务作品 ID 完整 |
| 缺少可选字段 | 不填写封面、播放量或备注 |
| 比例格式 | 点击率使用 `12.5%`，完播率使用 `0.36` |
| 重复数据 | 使用相同业务作品 ID 或书名作者组合 |
| 远程封面 | 使用公开、可访问、无敏感信息的测试图片 URL |
| 封面文件名 | 仅填写文件名，不触发远程封面创建 |

作品导入模板入口：`/import`

## 多书名测试结果样例

每本作品至少准备：

- 1 条对照组数据。
- 1-3 条实验组数据。
- 曝光量、点击率、转化率、完播率和收入至少填写一部分。
- 同时覆盖正向提升、效果混合和数据不足场景。

测试结果模板入口：`/experiments/import`

## 封面样例

- 优先使用无版权风险的占位图片。
- 本地图片只放在运行时 `uploads/`，不要提交 Git。
- 远程图片地址不要指向内网、localhost 或带鉴权参数的 URL。

## 验收顺序

1. 导入作品清单。
2. 对至少 2 本作品运行识别、评级、书名简介生成和封面评估。
3. 对 1 本作品保存最终审核结果。
4. 导入对应多书名测试结果并生成复盘、效果洞察。
5. 导出 Excel 和 ZIP，检查缺失数据不会中断交付。
