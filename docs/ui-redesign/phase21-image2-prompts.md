# 阶段 21 Image2 UI 概念稿 Prompts

更新时间：2026-05-31

所有概念稿均使用 Image2 生成，作为前端重构的视觉参考。生成图中的文字仅用于氛围和结构表达，实际页面文案以代码实现为准。

## 通用视觉约束

Use case: ui-mockup. High-fidelity enterprise SaaS admin dashboard for Chinese audiobook content operations. Premium Apple-inspired visual direction, calm and restrained, clean spacing, structured grid, readable cards, clear status hierarchy, modern side navigation, sticky header or section navigation where needed, data-rich but uncluttered, high usability, high legibility, content operations workflow. Light neutral background, white layered surfaces, graphite text, restrained blue primary accent, semantic green amber red status colors. Avoid cyber neon, heavy gradients, marketing landing page composition, oversized decorative cards, excessive rounded pills, clutter, watermarks.

## 页面 Prompts

### App Shell

Create a desktop app-shell concept showing a fixed left sidebar, compact top toolbar, breadcrumb, content canvas and restrained layered card surfaces. Navigation: 运营看板, 作品导入, 作品列表, 批量任务, 测试结果, 系统设置.

### Dashboard

Create an operations dashboard concept with summary hero, local-first and cost-control tags, recommended next action, grouped KPI cards, rating distribution, review status distribution, cover strategy distribution and action shortcuts.

### 作品导入

Create a professional four-stage import workflow: template download, drag-and-drop upload zone, rules checklist, validation summary and import status feedback.

### 作品列表

Create a dense but readable works list with search and filter toolbar, compact work rows, rating badges, review status, synopsis clamp, bulk action tray, page-size control and pagination.

### 单作品详情

Create a single-work operations console with summary header, next action, sticky section navigation and modules for identification, rating, title and intro suggestions, cover processing, experiment review, feedback insight and final approval.

### 批量任务中心

Create a batch job console with task list on the left, task detail on the right, blue running progress, green success, amber partial success, red failed, counters and expandable item details.

### 测试结果导入

Create a test-results import workflow with template download, drag-and-drop upload, field rule checklist, validation table, result summary and review-generation next action.

### 系统设置

Create a system runtime status center with operational status cards first, collapsible technical configuration second, search, OpenAI, database, uploads and cost policy status without exposing keys.

### 空状态：无作品

Create an empty-state UI illustration and interface concept for no imported works, with a calm file-stack motif and a clear primary action to import works.

### 空状态：无测试结果

Create an empty-state UI illustration and interface concept for no experiment results, with a restrained analytics motif and a clear primary action to import test results.
