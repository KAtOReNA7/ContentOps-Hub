## 共性差距与修复

| 维度 | 概念图特征 | 阶段 21 初版差距 | 阶段 21.1 修复 |
| --- | --- | --- | --- |
| 工作台壳层 | 品牌标识、稳定侧栏、当前项高亮、搜索区、运行状态 | 已有侧栏但品牌感和选中态偏弱 | 增强品牌标识、蓝色选中态、搜索占位、运行正常与成本受控状态 |
| 页面背景 | 冷白、浅灰分层，内容宽度稳定 | 基础背景已有，卡片层级不足 | 收敛最大内容宽度，统一冷白背景与浅边框阴影 |
| 卡片层级 | 大卡片有标题区、说明区、状态区，小卡片更轻 | 多数页面仍是平铺卡片 | `SectionCard` 支持标题、说明、状态和操作区；`StatCard` 强化 KPI 数字 |
| 状态语义 | success / running / warning / failed / neutral 颜色明确 | 状态映射存在但样式配置仍在组件内部 | 新增 `src/lib/ui/status-maps.ts`，统一 Badge 颜色 |
| 操作路径 | 首屏显示推荐下一步，主操作靠前 | 部分页面仍需要用户自行判断下一步 | Dashboard 和单作品摘要新增推荐下一步 |
| 长内容 | 默认先显示结论，详情渐进展开 | 长简介、备注和详情会增加页面高度 | 复用 `ExpandableText`，支持 1 / 2 / 3 行摘要 |

## Dashboard / 运营看板

### 差距

- 概念图有 Hero 总览、推荐下一步、流程概览、KPI、分布图和流程化快捷入口。
- 初版 Dashboard 虽已有统计卡片，但推荐动作与流程状态分离，首屏仍偏“统计集合”。
- 分布卡片没有复用统一 `MetricBar`。

### 修复

- 增加 Hero 双栏布局：左侧平台定位与主操作，右侧显示导入、识别、评级、审核流程概览。
- 根据数据自动生成推荐动作：导入作品、查看待审核、进入复盘、生成洞察或查看作品列表。
- KPI 改为紧凑 `StatCard`，待审核状态高亮。
- 分布区统一使用 `MetricBar`，数字右对齐并保持状态色语义。
- 快捷入口按运营流程排序，使用图标块、说明文字和 hover 状态。

## 作品列表页

### 差距

- 概念图是高密度可扫读列表：封面、书名、作者、品类、作品 ID、摘要、状态和详情入口聚合在一行。
- 初版卡片缺少封面缩略图，详情入口不够明确。
- 无作品空状态只有单一动作。

### 修复

- 查询最新封面资产并展示缩略图，无封面时展示占位。
- 简介限制为两行，备注等长内容不进入列表。
- 状态标签右侧聚合，新增明确的“查看详情”入口。
- 空状态增加“导入作品”和“手动新增作品”双入口。
- 批量操作未选中时保持折叠，选中后增加蓝色高亮。

## 单作品详情页

### 差距

- 概念图首屏是“单作品运营控制台”：封面、状态矩阵、价值评级、审核状态和推荐下一步集中呈现。
- 初版已有处理摘要和 sticky navigation，但摘要缺少封面，不够接近控制台式概览。
- 长简介和备注默认完整展示。

### 修复

- 首屏摘要增加最新封面缩略图，无封面时显示可操作占位。
- 将识别、评级、多书名建议、封面策略、测试复盘、效果洞察、最终审核集中为状态矩阵。
- 增加推荐下一步强调区。
- 保留并增强 sticky section navigation。
- 简介和备注使用渐进展开，先展示摘要再查看全文。

### 后续可继续精修

- 识别、评级、封面、复盘和最终审核面板内部已经具备业务能力，但仍可继续拆分为更强的结论区和折叠详情区。
- 封面处理可进一步增加原图与处理后结果的并排对比。

## 批量任务中心

### 差距

- 概念图采用任务列表与任务详情双栏控制台，成功、运行中、部分成功、失败颜色明确。
- 初版已经具备双栏和状态条，但卡片质感与页面体系略有差异。

### 修复

- 双栏容器统一为圆角、浅边框和轻阴影。
- 保留正确状态色：成功绿色、运行蓝色、部分成功橙色、失败红色、其他状态灰色。
- item 继续默认展示摘要，详细 JSON 不平铺。

## 作品导入页

### 差距

- 概念图强调步骤条、拖拽上传、模板下载、校验摘要和表格预览。
- 初版已有步骤、模板、规则和校验，但上传区仍像普通文件输入框。

### 修复

- 上传区改为拖拽式视觉区域，突出图标、支持格式和建议行数。
- 模板下载改为蓝色主按钮。
- 步骤条首步骤使用 active 状态。
- 规则继续折叠，导入校验结果保持结构化展示。

## 测试结果导入页

### 差距

- 与作品导入页相同，上传区缺少专业工作流质感。

### 修复

- 复用拖拽式上传区、主按钮和 active 工作流步骤。
- 保持对照组 / 实验组校验与复盘业务不变。

## 系统设置页

### 差距

- 概念图将设置页定位为运行状态中心：运营视图优先、安全策略明确、技术环境变量折叠。
- 初版已按运营视图和技术视图区分，但安全策略提示不够突出。

### 修复

- 增加安全与成本策略卡片。
- 保留 API Key 仅显示已配置 / 未配置，不显示任何明文。
- 保留技术配置折叠区域，避免运营人员首屏读取过多技术字段。

## 结论

阶段 21.1 已完成定向对齐：从基础样式统一进一步提升为更接近 Image2 概念图的企业级内容运营工作台。当前没有新增 API、数据库字段或业务流程，也没有调用外部 AI 服务。
