# 阶段 21 UI 概念稿采用记录

更新时间：2026-05-31

## 采用结论

本阶段采用全部 `final` 概念稿作为同一视觉方向。它们共享：固定左侧导航、紧凑顶部栏、浅灰页面背景、白色分层卡片、细边框、轻阴影、蓝色主操作和语义化状态色。

## 采用的设计元素

- App Shell：固定侧栏、顶部状态工具栏、统一内容宽度和页面背景。
- Dashboard：总览区、推荐下一步、KPI 分组、紧凑分布条和快捷操作。
- 作品列表：筛选区、紧凑作品行、按需展开批量操作、分页工具。
- 单作品详情：顶部摘要、下一步提示、sticky section nav、工作流式模块顺序。
- 批量任务中心：左侧任务列表、右侧详情、语义正确的进度颜色。
- 导入页：模板、上传、规则、校验和入库结果四段式组织。
- 设置页：运营状态优先、技术配置折叠、安全信息明确。
- 空状态：清晰说明当前缺失内容，并提供直接下一步入口。

## 仅作为参考的元素

- 概念稿中的图标、占位图片和具体数据不直接复制。
- 概念稿中的部分细节布局会根据现有业务组件和移动端约束简化。
- 不引入新的复杂图表库，分布图继续使用 Tailwind 横向进度条。

## 落地取舍

- 保留所有现有业务流程和 API，不进行数据结构迁移。
- 在现有组件上整理设计系统，不做大规模目录迁移。
- 优先重构全局骨架、首页、列表、详情、批量任务和设置页。
- 导入页面保留现有业务组件，通过统一页面头和容器层级提升流程感。
