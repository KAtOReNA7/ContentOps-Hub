# 人工审核状态流和最终采用结果

更新时间：2026-05-28

## 目标

阶段 13 补齐运营人员从“生成建议”到“最终采用”的记录闭环。系统不引入登录或复杂状态机，只在作品维度保存审核状态、最终书名、最终简介、最终封面和审核备注。

## 审核状态

作品支持以下审核状态：

- `pending_review`：待审核
- `approved`：已采用
- `rejected`：已退回
- `on_hold`：暂缓
- `needs_revision`：需修改

默认状态为 `pending_review`。

## 最终采用字段

阶段 13 直接扩展 `Work`，保持 MVP 简洁：

- `finalTitle`
- `finalIntro`
- `finalCoverUrl`
- `finalCoverAssetId`
- `finalCoverRenderId`
- `finalCoverSource`
- `reviewNote`
- `reviewedAt`
- `reviewerName`

`finalCoverUrl` 只保存应用内相对文件 API 地址，例如 `/api/cover-renders/{id}/file`，不保存服务器本地绝对路径。

## API

- `GET /api/works/[id]/review`：读取当前审核结果、可快速填入的书名/简介建议、可选择的封面结果。
- `POST /api/works/[id]/review`：保存审核状态、最终采用结果、审核备注和审核人。

封面选择来源包括：

- 原封面：`source=original_cover`
- 阶段 11 原图换标题：`source=local_sharp`
- 阶段 12 ChatGPT Image2 重绘：`source=chatgpt_image2`

## 页面

作品详情页新增“最终采用结果 / 人工审核”区域。运营人员可以：

- 设置审核状态
- 从新书名建议快速填入最终书名
- 从当前简介或新版简介快速填入最终简介
- 从原封面、阶段 11 结果、阶段 12 结果中选择最终封面
- 填写审核备注和审核人
- 保存后查看审核时间

作品列表页新增审核状态筛选，并在每条作品上显示当前审核状态。

## Excel 导出

导出新增：

- 审核状态
- 最终书名
- 最终简介
- 最终封面地址
- 最终封面来源
- 审核备注
- 审核人
- 审核时间

导出优先展示最终采用结果，同时保留原有识别、评级、书名简介、封面评估、阶段 11 和阶段 12 建议摘要。

## 手动测试

1. 运行 `npm run dev`。
2. 进入作品详情页。
3. 确认页面出现“最终采用结果 / 人工审核”区域。
4. 从候选书名中点击快速填入，确认最终书名更新。
5. 从简介选项中点击快速填入，确认最终简介更新。
6. 选择原封面、阶段 11 或阶段 12 的封面结果。
7. 设置审核状态、填写审核人和审核备注。
8. 点击“保存审核结果”，确认成功提示出现。
9. 刷新页面，确认审核状态和最终采用结果仍存在。
10. 返回作品列表，用审核状态筛选，确认列表结果正确。
11. 导出 Excel，确认新增审核字段存在，且最终采用结果优先展示。
