# 已知问题

更新时间：2026-05-30

| 问题 | 影响 | 当前处理 | 建议后续版本 |
| --- | --- | --- | --- |
| 批量任务依赖当前 Node 进程 | 服务重启后，未完成任务不会自动恢复 | 使用本地顺序执行，单条失败不影响整批 | 需要稳定后台执行时再引入持久化 worker |
| 真实搜索服务可能返回 HTTP 429 | 识别会变慢或进入 Mock fallback | 默认限制扩展 query 数，支持退避重试并提示 fallback | 根据实际供应商配额调整策略 |
| 真实搜索 provider 适配仍需业务选型 | 不同供应商返回字段和限流策略不同 | 保留 Mock-first 和 provider 抽象 | 确定正式供应商后补充契约测试 |
| 远程封面不强制下载到 ZIP | ZIP 可能缺少仅有远程 URL 的最终封面 | Excel 仍保留远程地址，ZIP 不因缺图失败 | 增加受控远程下载与缓存策略 |
| 封面评估为本地规则 | 不能理解图片视觉质量细节 | 用于 MVP 策略分流 | 未来可增加人工评分或可选视觉模型 |
| 效果回流为可解释规则 | 不提供统计显著性和机器学习预测 | 对运营复盘足够透明 | 数据量稳定后再评估统计模型 |
| npm audit 漏洞已归零 | 原依赖链曾有 PostCSS 中危问题和 xlsx 高危问题 | `postcss` 覆盖到 `8.5.15`，`xlsx` 使用 SheetJS 官方 CDN 修复包 `0.20.3` | 后续升级依赖时继续运行 `npm audit` 和完整构建检查 |
| Windows 上 Prisma 曾出现 schema engine 卡住 | 数据库同步命令可能受进程、杀软或路径影响 | 所有命令限制 60 秒，使用独立 `db:test` 脚本 | 卡住时先保存状态，再排查 Node 进程和 Defender |

## 安全边界

- 不提交 `.env`、`.env.local`、本地 SQLite 数据库和 `uploads/`。
- 不在前端、日志、文档或导出文件中展示 API Key。
- OpenAI、真实搜索和图片重绘均保持用户主动触发。
- 默认不批量生成图片。
