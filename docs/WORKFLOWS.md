# WORKFLOWS.md

## 核心流程

### 1. 导入或手动新增

- 入口：`/import`、`/works/new`
- 导入支持 Excel / CSV，先在前端解析和预览，再调用重复检查和入库 API。
- 手动新增支持作品 ID、书名、作者、分类、作品类型、简介、备注、运营指标、封面 URL 或本地封面。
- 人工介入点：修正表头、空书名、重复作品、比例格式、封面 URL 和作品类型。

### 2. 作品识别

- 入口：作品详情页“作品识别与搜索证据”。
- 默认使用 Mock，不调用真实搜索。
- 用户显式选择 configured search 并确认成本风险后，才读取服务端搜索配置。
- 识别结果保存候选、匹配结论、置信度、搜索 query、证据、风险和来源摘要。
- 人工介入点：低置信度、疑似重名、作者不一致、来源较弱时需要人工确认。

### 3. 价值评级

- 入口：作品详情页“OpenAI 作品价值评级中心”。
- 当前正式评级由 OpenAI 运行记录承载，结果不会自动覆盖采用评级。
- 用户明确采用后，评级结果投影到兼容表，供看板、生成和导出使用。
- 异常流程：OpenAI 配置缺失、请求失败、输出 invalid 时保存失败状态，不回退 rules。
- 人工介入点：补充平台、IP、榜单、作者、运营等证据后重新评级。

### 4. 书名简介生成

- 入口：作品详情页“书名和简介优化”。
- 支持 Mock 本地规则和 OpenAI 文本 provider。
- 生成结果保存标题变体、简介变体、封面 Prompt、策略、风险和证据。
- 异常流程：OpenAI 配置缺失或调用失败时返回明确错误，不静默回退 Mock。
- 人工介入点：选择最终书名、最终简介和是否继续优化。

### 5. 封面评估与处理

- 入口：作品详情页“封面评估与处理建议”。
- 封面资产来源包括本地上传和远程 URL。
- Mock 封面评估输出评分、评级、优缺点、策略和原因。
- 原图换标题可生成 1:1 和 3:4 结果。
- Image2 重绘只允许单本手动触发，不默认批量执行。
- 人工介入点：确认封面策略、选择最终封面、决定是否重绘。

### 6. 人工审核

- 入口：作品详情页“最终采用结果 / 人工审核”。
- 保存审核状态、最终书名、最终简介、最终封面、审核备注和审核人。
- 审核状态包括 `pending_review`、`approved`、`rejected`、`on_hold`、`needs_revision`。
- 人工介入点：所有最终采用字段都必须允许人工确认和修正。

### 7. 多书名测试结果回流

- 入口：`/experiments/import` 和作品详情页测试复盘区域。
- 使用独立模板导入对照组和实验组数据。
- 系统按本地规则生成复盘结论和推荐动作。
- 异常流程：数据不足时只生成风险提示，不强行得出成功结论。

### 8. 效果洞察

- 入口：作品详情页“效果回流 / 评分校准”。
- 基于实验复盘、原始评级、标题策略和封面策略生成可解释洞察。
- 不自动覆盖最终采用结果。
- 人工介入点：判断洞察是否用于后续运营策略或评分校准。

### 9. Excel 或 ZIP 导出

- 入口：作品列表、单作品详情、导出 API。
- Excel 支持单本、全部、当前筛选和勾选导出。
- ZIP 包含 Excel 和可读取到的本地最终封面。
- 异常流程：缺少识别、评级、生成或封面结果时导出不应失败；缺少最终封面时 ZIP 仍应导出。

### 10. 批量任务查看和重试

- 入口：作品列表批量操作、`/analysis` 批量任务中心。
- 支持批量识别、评级、书名简介生成和封面评估。
- 任务项独立记录 `success`、`failed`、`skipped`、错误和摘要。
- 失败项可在任务中心重试。
- 当前限制：任务执行依赖当前 Node 进程，服务重启后无法跨进程恢复。

## 通用异常流程

- 外部 API 未配置：返回结构化错误，不伪装成功。
- 真实搜索失败：允许 Mock fallback，但必须明确标记 `searchFallback` 和实际 provider。
- OpenAI 失败：保存 failed / invalid，不回退 rules 或 Mock 作为正式结果。
- 文件缺失：导出和封面读取应返回明确错误或跳过，不泄露本地绝对路径。
- 批量单条失败：不影响整批继续执行。
