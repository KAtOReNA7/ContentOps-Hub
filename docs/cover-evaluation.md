# 封面评估与处理策略

更新时间：2026-05-24

## 目标

阶段 9 支持当前作品封面图的接入、预览、基础评分、处理策略判断和人工确认。

本阶段不接图片生成 API，不调用图片生成服务，也不真正重绘图片。

## 数据结构

新增两类数据：

- `CoverAsset`：保存作品当前封面文件的基础信息。
- `WorkCoverEvaluation`：保存封面评分、评级、优缺点、处理策略、策略理由和人工确认状态。

上传的真实封面文件保存在本地 `uploads/covers/{workId}/`，该目录已加入 `.gitignore`，不应提交到 Git。

## 上传限制

当前支持：

- JPEG
- PNG
- WebP

当前限制：

- 最大 5MB
- 必须通过作品详情页上传
- 只保存本地文件和数据库元数据，不上传到外部对象存储

## Mock 评估逻辑

当前封面评估是本地 Mock / 规则评估，不使用 OpenAI 视觉能力。

评分考虑：

- 文件格式是否适合 Web 预览和后续处理
- 文件体积是否处于合理范围
- 文件名与作品名是否有关联
- 作品品类是否可用于后续封面风格判断

输出结构：

- `score`：0-100
- `rating`：A/B/C/D
- `strengths`：优点
- `weaknesses`：问题
- `strategy`：处理策略
- `reason`：策略理由

## 处理策略

`strategy` 只允许三种：

- `keep_and_replace_title`：当前封面质量优秀，后续只基于新书名替换封面标题。
- `keep_and_optimize_layout`：当前封面质量一般，保留主体画面，后续优化标题区、字号、对比度和版式。
- `redraw_cover`：当前封面质量较差，后续才进入重新绘制封面。

## 人工确认

作品详情页可以：

- 查看最新封面评估结果
- 修改确认策略
- 填写审核备注
- 保存人工确认状态

人工确认不会修改原始作品数据，也不会触发图片生成。

## 当前限制

- 不识别图片真实尺寸。
- 不做 OCR。
- 不判断画面主体是否真实匹配作品内容。
- 不接 OpenAI 视觉。
- 不生成新封面图片。
- 不做批量封面处理。

后续如果进入图片生成阶段，应继续保留当前策略判断作为前置审核，避免默认批量生成图片造成成本失控。

## 导入封面 URL 支持

更新时间：2026-05-24

- `CoverAsset` 支持两类来源：`local_upload` 和 `remote_url`。
- `local_upload` 表示作品详情页手动上传的本地封面文件，继续使用 `storagePath`。
- `remote_url` 表示从导入表格读取的远程图片地址，保存 `remoteUrl`，`storagePath` 可以为空。
- 导入阶段不会下载远程图片，也不会批量校验远程图片，避免拖慢导入流程。
- 作品详情页通过 `/api/cover-assets/{id}/file` 代理预览远程封面。
- 远程封面代理只允许 http/https，阻止 localhost、127.0.0.1、0.0.0.0 和常见内网 IP 段，并限制 timeout、content-type 和响应体大小。
- Mock 封面评估会记录封面来源，但当前不做 OpenAI 视觉评估，也不生成图片。
